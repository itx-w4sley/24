24xzvibx Creative Studio 5.0
=======================================

This ZIP is the FULL NEXT.JS WEBSITE SOURCE, including React, backend API routes, client portal, admin console, styles and MongoDB setup scripts.
It is NOT a single HTML file and not a precompiled Windows application.

QUICK SETUP (Windows PowerShell):
  1. Extract ZIP.
  2. Open PowerShell inside the extracted folder.
  3. Run: npm install
  4. Run: Copy-Item .env.example .env.local
  5. Edit .env.local with your own MongoDB Atlas URI, secret and admin credentials.
  6. Run: npm run setup
  7. Run: npm run dev
  8. Browse: http://localhost:3000

ADMIN: http://localhost:3000/admin
CLIENT: http://localhost:3000/portal

TO PRESERVE YOUR OLD ARTWORK:
  Copy all 33 image files from your previous site's assets folder into
  public/assets/ with their original filenames.
  Without the original images, the website shows tasteful placeholders.

For Vercel deployment, security, services and MongoDB instructions, read README.md.
No credentials or client data are included in this archive.
